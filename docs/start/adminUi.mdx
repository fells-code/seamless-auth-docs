## Explore the Admin Dashboard

The Seamless Auth Admin UI is the operator-facing application for managing and investigating a
Seamless Auth deployment.

It runs as a separate app and uses the same auth system as the rest of your stack.

---

## Access Requirements

Only users with the `admin` role should be able to access the dashboard.

In the current dashboard app:

- unauthenticated users are redirected to `/unauthenticated`
- authenticated non-admin users should not reach the main operator routes
- admin access depends on the `admin` role being present in the authenticated session

<Callout type="info">
  The dashboard is an operational tool, not a hidden control plane. It works through explicit API
  routes and the same role data your application can inspect.
</Callout>

---

## Main Areas

The current dashboard app includes:

- Overview
- Users
- Sessions
- Events
- Security
- System configuration
- Profile

The most important starter-path sections are the first six.

## How It Connects To The Stack

The dashboard sits on top of:

- admin routes such as `/admin/*`
- internal metrics routes such as `/internal/*`
- system config routes such as `/system-config/*`

If you want the technical route map, see [Auth API Routes](/docs/reference/auth-api-routes).
