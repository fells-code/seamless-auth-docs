# What is Seamless Auth?

Seamless Auth is an open source, passwordless authentication system designed to run as part of your application infrastructure.

It provides a small, explicit core and framework-specific integrations that allow you to add modern authentication without redirects, hosted identity UIs, or external dependencies.

Seamless Auth can be run locally, self-hosted, or deployed as isolated infrastructure per environment.

---

## The Problem

Authentication is often the most complex and least controlled part of an application.

Traditional approaches rely on passwords, redirect-based OAuth flows, and shared multi-tenant identity providers. These patterns introduce several issues:

- Passwords are inherently insecure and difficult to manage safely
- Redirects and callbacks complicate application architecture
- Tokens are often exposed to the browser or stored client-side
- Authorization logic becomes tightly coupled to external providers
- Local development environments rarely reflect production behavior

The result is a system that is difficult to reason about, difficult to debug, and difficult to trust.

---

## The Seamless Auth Approach

Seamless Auth treats authentication as infrastructure.

Instead of redirecting users away from your application or relying on hosted identity flows, Seamless Auth runs alongside your services and integrates directly with your frontend and backend.

Authentication becomes part of your system, not something that sits outside of it.

Key characteristics:

- **Passwordless by default**  
  Authentication is based on cryptographic verification, not shared secrets.

- **Embedded authentication**  
  Auth flows are part of your application. There are no redirects or external UI layers.

- **Server-side session validation**  
  Sessions are issued and validated using secure, HTTP-only cookies.

- **Explicit authorization**  
  Roles and access control are defined and enforced in your own code.

- **Consistent environments**  
  The same model works locally, in staging, and in production.

---

## Open Source and Extensible

Seamless Auth is built as an open system with clear separation between core logic and integrations.

- A framework-agnostic core handles cryptography, verification, and identity resolution
- Thin adapters integrate Seamless Auth into server frameworks
- Starter templates demonstrate full, working systems without hiding complexity

This makes it possible to extend or adapt the system without rewriting core components.

---

## Technology Overview

Seamless Auth is built on modern web standards and explicit infrastructure primitives.

### WebAuthn and Passkeys

Seamless Auth uses WebAuthn and Passkeys to provide secure, phishing-resistant authentication without passwords.

Credential registration, challenge generation, and verification are handled by the auth server. Your application interacts only with verified session state.

### Secure Cookies and Token Verification

Sessions are represented using short-lived, HTTP-only cookies.

Tokens are signed and exposed via JSON Web Key Sets (JWKS), allowing APIs to validate sessions independently without relying on an external identity provider.

### Infrastructure-Oriented Design

Seamless Auth is designed to run as part of your infrastructure:

- Local development via Node.js or Docker Compose
- Deployment using containers or infrastructure platforms
- Configuration through environment variables and code

There are no required hosted services and no hidden components.
