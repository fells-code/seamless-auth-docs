# What is Seamless Auth?

Seamless Auth is an open source, passwordless authentication system designed to be embedded directly into your application.

It provides a small, explicit core and framework-specific integrations that allow you to add modern authentication without redirects, third-party hosted UIs, or opaque identity infrastructure.

Seamless Auth can be self-hosted entirely, run locally for development, or deployed as isolated infrastructure per environment.

---

## The Problem

Authentication is often the most complex and least understood part of an application.

Traditional systems rely on passwords, redirect-based OAuth flows, and shared multi-tenant identity providers. These approaches introduce several issues:

- Passwords are insecure and difficult to protect
- Redirects and callbacks complicate application architecture
- Tokens are often exposed to the browser or client-side storage
- Authorization logic becomes tightly coupled to identity providers
- Local development rarely matches production behavior

As a result, developers spend significant time integrating, debugging, and securing authentication instead of building product features.

---

## The Seamless Auth Approach

Seamless Auth is built around a simple idea:

> Authentication should behave like any other piece of application infrastructure.

Instead of redirecting users away from your app or relying on hosted identity flows, Seamless Auth runs as part of your system and integrates directly with your frontend and backend.

Key characteristics:

- **Passwordless by default**
  Authentication is based on possession and cryptographic verification, not shared secrets.
- **Embedded authentication**
  Auth flows live inside your application. There are no redirects, callbacks, or iframes.
- **Server-side session validation**
  Sessions are managed using secure, HTTP-only cookies and validated by your API.
- **Explicit authorization**
  Roles and access checks are enforced directly in application code.
- **Local-first development**
  The same authentication model works in development, staging, and production.

---

## Open Source and Extensible

Seamless Auth is built as an open source system with clear separation between core logic and framework adapters.

- A framework-agnostic core handles cryptography, verification, and identity resolution
- Thin adapters integrate Seamless Auth into popular server frameworks
- Starter templates demonstrate real-world usage without hiding complexity

This design makes it straightforward to add new integrations or adapt Seamless Auth to different runtimes.

---

## Technology Overview

Seamless Auth is powered by modern web standards and explicit infrastructure primitives.

### WebAuthn and Passkeys

Seamless Auth uses **WebAuthn** and **Passkeys** to provide secure, phishing-resistant authentication without passwords.

Credential registration, challenge generation, and verification are handled by the auth server. Your application only consumes verified session state.

### Secure Cookies and Token Verification

Authenticated sessions are represented using short-lived, HTTP-only cookies.

Tokens are signed and verifiable using **JSON Web Key Sets (JWKS)**, allowing APIs to validate sessions without contacting an external identity provider.

### Explicit Infrastructure

Seamless Auth is designed to run as part of your infrastructure:

- Local development via Node.js or Docker Compose
- Deployment using container-based platforms
- Configuration via environment variables and infrastructure-as-code

There are no hidden services or required hosted dependencies.

Seamless Auth is a good fit if you:

- Want passwordless authentication without redirects
- Prefer explicit, code-level control over auth and authorization
- Need a local development environment that mirrors production
- Value open source, inspectable systems
- Want to avoid vendor lock-in for identity infrastructure
