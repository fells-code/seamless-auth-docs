# Server SDK

The **SeamlessAuth Server SDK** provides everything you need to add passwordless authentication to your backend — including token validation, verification, and route handlers for common auth endpoints.

This SDK is **framework-agnostic**, but examples below use **Express** for simplicity.

---

## Installation

Install the server SDK into your backend project:

```bash
npm install @seamless-auth/server
```

You’ll also need `express` if you’re starting from scratch:

```bash
npm install express
```

---

## Overview

The Server SDK includes:

- Middleware for validating and verifying tokens
- Helper utilities for session management
- Prebuilt router endpoints for passwordless authentication flows (WebAuthn, OTP, and email/phone verification)

It works out of the box with the same SeamlessAuth infrastructure provisioned for your project — no extra configuration required.

---

## Basic Usage

### Create a simple Express server

```ts
import express from 'express'
import { SeamlessAuth } from '@seamless-auth/server'

const app = express()
const seamless = new SeamlessAuth({
  apiKey: process.env.SEAMLESS_API_KEY,
  jwtSecret: process.env.SEAMLESS_JWT_SECRET,
  origin: process.env.SEAMLESS_ORIGIN,
})

// parse JSON request bodies
app.use(express.json())

// use SeamlessAuth routes
app.use('/auth', seamless.router())

// example protected route
app.get('/profile', seamless.validateToken, (req, res) => {
  res.json({ message: `Hello ${req.user.email}` })
})

// start server
app.listen(5001, () => console.log('Server running on http://localhost:5001'))
```

> The `.router()` method mounts all SeamlessAuth endpoints automatically under `/auth`.

---

## Middleware

### 🔹 `validateToken`

Ensures requests include a valid SeamlessAuth JWT in the `Authorization` header or secure cookie.

```ts
app.get('/secure', seamless.validateToken, (req, res) => {
  res.json({ user: req.user })
})
```

If validation fails, the request is rejected with a `401 Unauthorized` response.

---

### 🔹 `verifyToken`

Use this helper manually when you want to validate a token without Express middleware.

```ts
try {
  const decoded = await seamless.verifyToken(token)
  console.log(decoded.sub) // user id
} catch {
  console.error('Invalid token')
}
```

## Built-in Routes

The SeamlessAuth Server SDK automatically provides standard authentication routes when you mount `seamless.router()`.

Below is a list of all the handlers included out of the box:

| Endpoint                             | Method   | Description                                     |
| ------------------------------------ | -------- | ----------------------------------------------- |
| `/auth/login`                        | `POST`   | Begins a passwordless login flow                |
| `/auth/logout`                       | `POST`   | Ends the user session                           |
| `/auth/generateWebAuthnLogin`        | `POST`   | Returns a challenge for WebAuthn login          |
| `/auth/generateWebAuthnRegistration` | `POST`   | Returns a challenge for WebAuthn registration   |
| `/auth/verifyWebAuthnLogin`          | `POST`   | Verifies a WebAuthn login attempt               |
| `/auth/verifyWebAuthnRegistration`   | `POST`   | Verifies and registers new WebAuthn credentials |
| `/auth/sendPhoneOTP`                 | `POST`   | Sends an OTP to a user’s phone                  |
| `/auth/sendEmailOTP`                 | `POST`   | Sends a magic link or OTP to an email address   |
| `/auth/verifyPhoneOTP`               | `POST`   | Verifies a one-time password sent via SMS       |
| `/auth/verifyEmailOTP`               | `POST`   | Verifies a one-time password sent via email     |
| `/auth/register`                     | `POST`   | Registers a new user                            |
| `/auth/me`                           | `GET`    | Returns the current authenticated user          |
| `/auth/delete`                       | `DELETE` | Deletes the authenticated user account          |

## Example: WebAuthn Registration Flow

```ts
// 1. Generate a WebAuthn registration challenge
app.post('/auth/generateWebAuthnRegistration', seamless.router())

// 2. On client completion, verify registration
app.post('/auth/verifyWebAuthnRegistration', seamless.router())
```

The SDK automatically handles challenge generation, verification, and user record creation.

## Example: OTP Flows

### Email OTP

```ts
// Send OTP

// Verify OTP

```

### Phone OTP


## Example: Protected API Route

```ts
app.get('/dashboard', seamless.validateToken, (req, res) => {

  res.json({ message: `Welcome back, ${user.email}` })
})
```

---

## Notes

- You can mount `seamless.router()` at any path — for example `/api/auth` instead of `/auth`.
- Tokens are automatically verified against your project’s JWKS keys.
- If using cookies, enable `cookie-parser` before `validateToken`.
