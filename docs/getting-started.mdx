# Getting Started

Seamless Auth runs a complete passwordless authentication stack locally.

This guide walks you from zero → working environment with the fewest possible surprises.

You have two setup paths:

- **Docker (recommended)** – fastest, least friction
- **Manual setup** – for full control or custom environments

---

## Step 1 — Environment Check

Before generating your project, confirm one of the following setups.

---

### Option A — Docker (Recommended)

You need:

- Docker
- Docker Compose

Verify installation:

```bash
docker --version
docker compose version
```

If not installed, download Docker Desktop:

[https://www.docker.com/products/docker-desktop](https://www.docker.com/products/docker-desktop)

> **Why Docker?**
> Docker eliminates local Postgres setup, environment drift, and version conflicts.

---

### Option B — Manual Setup (No Docker)

You need:

- Node.js ≥ 20
- npm or pnpm
- PostgreSQL running locally or remotely

Check Node:

```bash
node -v
```

Check Postgres:

```bash
psql --version
```

If Postgres is not installed:

- macOS: `brew install postgresql`
- Ubuntu: `sudo apt install postgresql`
- Windows: Official PostgreSQL installer

> ⚠️ If Postgres is not running, Seamless Auth will fail to start.

---

## Option 1 — Quick Start with Docker

Generate a project:

```bash
npx create-seamless my-app
cd my-app
```

Start the stack:

```bash
docker compose up
```

This launches:

- Postgres
- Seamless Auth server
- Express API
- React (Vite) web app

Open:

```
http://localhost:5001
```

### ⚠️ Common Docker Issue: Port 5432 Already In Use

If you already have Postgres running locally, you may see:

```
Bind for 0.0.0.0:5432 failed: port is already allocated
```

Fix by editing `docker-compose.yml`:

```yaml
ports:
  - '5433:5432'
```

Only the **host port** changes. Internal networking remains unchanged.

> Containers still connect to Postgres via service name `db`.

## Option 2 — Manual Setup (No Docker)

If not using Docker, follow these steps carefully.

---

### Create Databases

Start Postgres and run:

```bash
cd auth
npm run db:create
```

```bash
cd api
npm run db:create
```

---

### Run Migrations

If tables are not created automatically:

```bash
cd auth
npm run migrate:up
```

```bash
cd api
npm run migrate:up
```

---

### Start Services

In separate terminals:

```bash
cd auth && npm install && npm run dev
```

```bash
cd api && npm install && npm run dev
```

```bash
cd web && npm install && npm run dev
```

Open:

```
http://localhost:5001
```

## Troubleshooting

### Cannot Connect to Database

Checklist:

- Is Postgres running?
- Are credentials correct?

---

### Passkey Not Supported

Ensure:

- You are using a modern browser (Chrome, Safari, Edge, Firefox)
- You are running on `localhost` or HTTPS
