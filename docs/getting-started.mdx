# Getting Started

Seamless Auth runs a complete passwordless authentication stack locally.

This guide takes you from zero to a working system with the same architecture used in production.

There are two ways to run the stack:

- Docker — fastest setup, no local dependencies
- Manual setup — more control, requires local services

---

## Step 1 — Environment Check

Before creating a project, confirm your environment.

---

### Option A — Docker (Recommended)

Requirements:

- Docker
- Docker Compose

Verify installation:

```bash
docker --version
docker compose version
```

If Docker is not installed:

[https://www.docker.com/products/docker-desktop](https://www.docker.com/products/docker-desktop)

Docker avoids local database setup and keeps environments consistent.

---

### Option B — Manual Setup

Requirements:

- Node.js ≥ 20
- npm or pnpm
- PostgreSQL

Check Node:

```bash
node -v
```

Check Postgres:

```bash
psql --version
```

If Postgres is not installed:

- macOS: `brew install postgresql`
- Ubuntu: `sudo apt install postgresql`
- Windows: Official PostgreSQL installer

Postgres must be running before starting the auth server.

---

## Option 1 — Quick Start with Docker

Create a project:

```bash
npx create-seamless my-app
cd my-app
```

Start the stack:

```bash
docker compose up
```

This starts:

- Postgres
- Auth server
- API server
- Web app

Open:

```
http://localhost:5173
```

### Port Conflict: 5432 Already In Use

If you already have Postgres running locally:

```
Bind for 0.0.0.0:5432 failed: port is already allocated
```

Update `docker-compose.yml`:

```yaml
ports:
  - '5433:5432'
```

Only the host port changes. Containers still connect using `db`.

## Option 2 — Manual Setup

If you are not using Docker, run each service directly.

---

### 1. Start PostgreSQL

Ensure Postgres is running on:

```
localhost:5432
```

---

### 2. Initialize the Auth Server

```bash
cd auth
npm install

npm run db:create
npm run db:migrate
```

---

### 3. Initialize the API

```bash
cd api
npm install

npm run db:create
npm run db:migrate
```

---

### 4. Start Services

Run each service in a separate terminal:

```bash
cd auth && npm run dev
```

```bash
cd api && npm run dev
```

```bash
cd web && npm run dev
```

Open:

```
http://localhost:5173
```

---

## Troubleshooting

### Cannot Connect to Database

Check:

- Postgres is running
- Database credentials match your `.env`

---

### Passkeys Not Working

Ensure:

- You are using a modern browser
- You are on `localhost` or HTTPS
- You are not inside an unsupported iframe context

---

## Development Notes

- OTP codes are logged to the console in development
- No external SMS or email provider is required locally
- Sessions use HTTP-only cookies on localhost
