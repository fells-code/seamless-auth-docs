# Auth Events & Auditing

SeamlessAuth tracks authentication activity through **auth events**.

These provide visibility into:

- User behavior
- Security events
- System activity

---

## Mental Model

```
User Action → Auth Event Recorded → Stored → Analyzed
```

---

## What is an Auth Event?

An auth event is a record of something that happened in the auth system.

Examples:

- user_created
- registration_success
- verify_otp_success
- webauthn_registration_success

---

## Event Fields

| Field      | Description        |
| ---------- | ------------------ |
| id         | Event ID           |
| user_id    | Associated user    |
| type       | Event type         |
| ip_address | Origin IP          |
| user_agent | Device info        |
| metadata   | Additional context |

---

## Why Auth Events Matter

Auth events allow you to:

- Debug authentication issues
- Monitor system activity
- Detect suspicious behavior
- Build analytics dashboards
